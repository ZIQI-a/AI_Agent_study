## 核心学习原则

1. **先概念后代码**：理解原理再动手
2. **先 TypeScript 后 Python**：用你熟悉的技术栈入门
3. **先模仿后创造**：跑通官方示例，再自己改
4. **先单点后系统**：一个 API → 一个对话 → 一个 Agent → 完整应用
