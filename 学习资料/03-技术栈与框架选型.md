## 2. AI 应用框架（必学）

### 2.1 Vercel AI SDK —— 前端开发者首选

```
为什么选它：
  ✅ TypeScript 原生
  ✅ 与 Next.js/React 深度集成
  ✅ 流式响应开箱即用
  ✅ 支持多家 LLM 提供商
  ✅ 前端 Hooks 直接用

核心能力：
  - useChat()     → 对话式 UI Hook
  - useCompletion() → 文本补全 Hook
  - streamText()  → 流式文本生成
  - generateObject() → 结构化输出
  - tool()        → 工具定义

安装：
  pnpm add ai @ai-sdk/openai  # 或 @ai-sdk/anthropic
```

```typescript
// 最简示例：流式对话
// app/api/chat/route.ts
import { streamText } from "ai";
import { openai } from "@ai-sdk/openai";

export async function POST(req: Request) {
  const { messages } = await req.json();
  const result = streamText({
    model: openai("gpt-4o"),
    system: "你是一个有帮助的助手",
    messages,
  });
  return result.toDataStreamResponse();
}

// 前端组件
import { useChat } from "@ai-sdk/react";

export function Chat() {
  const { messages, input, handleInputChange, handleSubmit } = useChat();
  return (
    <form onSubmit={handleSubmit}>
      {messages.map((m) => (
        <div key={m.id}>{m.role}: {m.content}</div>
      ))}
      <input value={input} onChange={handleInputChange} />
    </form>
  );
}
```

### 2.2 LangChain / LangGraph —— Agent 开发首选

```
为什么选它：
  ✅ Agent 生态最完善
  ✅ LangGraph 专为复杂 Agent 设计
  ✅ Python 和 TypeScript 都有
  ✅ 社区最大，教程最多
  ✅ 支持所有主流 LLM

核心组件：
  - ChatModel     → LLM 调用
  - Tools         → 工具定义
  - Agent         → Agent 编排
  - Memory        → 记忆管理
  - Chain         → 链式调用
  - LangGraph     → 状态图编排

安装：
  pnpm add langchain @langchain/core @langchain/openai
  pnpm add @langchain/langgraph  # Agent 状态图
```

```typescript
// LangGraph Agent 示例
import { ChatOpenAI } from "@langchain/openai";
import { createReactAgent } from "@langchain/langgraph/prebuilt";
import { tool } from "@langchain/core/tools";
import { z } from "zod";

// 定义工具
const weatherTool = tool(
  async ({ city }) => {
    // 实际调用天气 API
    return `${city}今天晴，25°C`;
  },
  {
    name: "get_weather",
    description: "查询城市天气",
    schema: z.object({ city: z.string().describe("城市名") }),
  }
);

// 创建 Agent
const model = new ChatOpenAI({ model: "gpt-4o" });
const agent = createReactAgent({ llm: model, tools: [weatherTool] });

// 使用
const result = await agent.invoke({
  messages: [{ role: "user", content: "北京今天天气怎么样？" }],
});
```

### 2.3 框架选型建议

```
你的目标                    推荐框架
──────────                  ─────────
快速做 AI 对话页面    →     Vercel AI SDK
构建复杂 Agent        →     LangGraph
做 RAG 知识库         →     LlamaIndex
可视化编排（低代码）   →     Dify / Coze
全栈 AI 应用          →     Vercel AI SDK + LangGraph
Python 后端服务       →     LangChain Python
```

## 3. 向量数据库（RAG 必备）

### 3.1 选型对比

| 数据库 | 类型 | 特点 | 适用场景 |
|--------|------|------|---------|
| **Chroma** | 嵌入式 | 轻量、易上手 | 原型开发、小项目 |
| **Pinecone** | 云服务 | 托管、免运维 | 生产环境 |
| **Weaviate** | 自托管/云 | 功能丰富 | 企业级应用 |
| **Milvus** | 自托管 | 高性能 | 大规模数据 |
| **pgvector** | PG 扩展 | 复用现有 PG | 已有 PostgreSQL 的项目 |
| **LanceDB** | 嵌入式 | 本地优先、零配置 | 原型和本地开发 |

### 3.2 快速上手（Chroma）

## 7. 推荐技术组合

### 方案 A：前端全栈（推荐入门）
```
Next.js + Vercel AI SDK + OpenAI/Claude + Chroma
优势：全 TypeScript、部署简单、学习曲线平缓
适合：AI 对话页面、简单 RAG、Copilot 类应用
```

### 方案 B：Agent 专项
```
LangGraph + LangSmith + OpenAI/Claude + 向量数据库
优势：Agent 能力最强、生态最完善
适合：复杂 Agent、多 Agent、工作流应用
```

### 方案 C：全栈 Agent
```
Next.js (前端) + LangGraph (Agent) + Vercel AI SDK (流式) + Pinecone (向量)
优势：兼顾前端体验和 Agent 能力
适合：生产级 AI 应用
```

### 方案 D：低代码快速验证
```
Dify / Coze + API 集成
优势：无需写代码、快速上线
适合：验证想法、非技术团队
```
