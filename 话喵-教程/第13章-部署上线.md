## 13.2 SQLite 在生产环境的问题

SQLite 是文件数据库，在 Vercel 的 Serverless 环境中有限制：

```
本地开发：SQLite 文件存在磁盘上，读写正常
Vercel：  Serverless 函数是临时的，文件系统不持久

解决方案：
  方案 A：使用 Turso（SQLite 兼容的云数据库）← 推荐
  方案 B：使用 Vercel Postgres
  方案 C：使用 Drizzle + PlanetScale
```

### 方案 A：使用 Turso（推荐）

Turso 是 SQLite 的云版本，兼容 SQLite 语法。

```bash
# 安装 Turso CLI
curl -sSfL https://get.tur.so/install.sh | bash

# 登录
turso auth login

# 创建数据库
turso db create huamiao

# 获取连接 URL
turso db show huamiao --url
# 输出类似：libsql://huamiao-你的用户名.turso.io

# 创建认证 Token
turso db tokens create huamiao
# 输出类似：eyJhbGciOiJFZDI1NTE5...
```

### 修改数据库配置

```bash
pnpm add @libsql/client
```

修改 `src/lib/db/index.ts`：

```typescript
import { drizzle } from "drizzle-orm/libsql";
import { createClient } from "@libsql/client";
import * as schema from "./schema";

// 根据环境选择数据库
const client = createClient({
  url: process.env.TURSO_DATABASE_URL || "file:data/huamiao.db",
  authToken: process.env.TURSO_AUTH_TOKEN,
});

export const db = drizzle(client, { schema });
```

## 13.4 部署到 Vercel

### 方式一：Vercel 网站部署

1. 打开 [vercel.com](https://vercel.com)
2. 用 GitHub 账号登录
3. 点击「New Project」
4. 选择你的 `huamiao` 仓库
5. 配置环境变量：
   - `DEEPSEEK_API_KEY`
   - `TURSO_DATABASE_URL`
   - `TURSO_AUTH_TOKEN`
6. 点击「Deploy」

### 方式二：Vercel CLI 部署

```bash
# 安装 Vercel CLI
npm i -g vercel

# 登录
vercel login

# 部署
vercel

# 设置环境变量
vercel env add DEEPSEEK_API_KEY
vercel env add TURSO_DATABASE_URL
vercel env add TURSO_AUTH_TOKEN

# 重新部署（使环境变量生效）
vercel --prod
```

## 13.5 Drizzle 配置更新

更新 `drizzle.config.ts` 以支持 Turso：

```typescript
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  schema: "./src/lib/db/schema.ts",
  out: "./drizzle",
  dialect: "sqlite",
  dbCredentials: {
    url: process.env.TURSO_DATABASE_URL || "data/huamiao.db",
    authToken: process.env.TURSO_AUTH_TOKEN,
  },
});
```

生产环境执行迁移：

```bash
# 使用 Turso 的 URL 执行迁移
TURSO_DATABASE_URL=xxx TURSO_AUTH_TOKEN=xxx pnpm db:push
```

## 13.6 自定义域名

1. 在 Vercel 项目设置中找到「Domains」
2. 输入你的域名（如 `huamiao.com`）
3. 按提示配置 DNS 记录
4. 等待 SSL 证书自动配置

## 13.8 常见部署问题

**问题 1：构建失败**
```bash
# 本地测试构建
pnpm build

# 查看错误日志，通常是类型错误或依赖问题
```

**问题 2：API 调用失败**
```
检查环境变量是否正确配置在 Vercel 中
注意：Vercel 的环境变量需要重新部署才生效
```

**问题 3：数据库连接失败**
```
确认 Turso URL 和 Token 正确
确认已执行数据库迁移
```
