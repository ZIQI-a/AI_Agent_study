# 附录：常见问题与排错

## 安装问题

### pnpm 安装失败

```
问题：pnpm : 无法加载文件，因为在此系统上禁止运行脚本

解决（Windows）：
  以管理员身份运行 PowerShell
  Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
  
解决（Mac/Linux）：
  检查 Node.js 是否正确安装：node -v
  重新安装 pnpm：npm install -g pnpm
```

### shadcn/ui 初始化失败

```
问题：npx shadcn@latest init 报错

解决：
  1. 确保在项目根目录执行
  2. 确保已安装 Tailwind CSS
  3. 尝试清除缓存：pnpm dlx shadcn@latest init
  4. 检查 Node.js 版本 >= 18
```

### 依赖安装冲突

```
问题：peer dependency 冲突

解决：
  pnpm install --force
  或删除 node_modules 重新安装：
  rm -rf node_modules pnpm-lock.yaml
  pnpm install
```

## API 问题

### API Key 无效

```
问题：401 Unauthorized

检查：
  1. API Key 是否正确复制（没有多余空格）
  2. 环境变量文件是否是 .env.local（不是 .env）
  3. 重启开发服务器使环境变量生效
  4. 在平台检查 Key 是否过期或被禁用
```

### 余额不足

```
问题：402 Payment Required

解决：
  DeepSeek：登录 platform.deepseek.com 充值
  通义千问：登录阿里云控制台开通 DashScope
```

### 请求过于频繁

```
问题：429 Too Many Requests

解决：
  1. 等待几分钟后重试
  2. 降低请求频率
  3. 使用缓存减少重复请求
```

### 流式响应不工作

```
问题：页面一直加载，没有逐字输出

检查：
  1. API Route 是否使用了 streamText（不是普通的 chat.completions.create）
  2. 是否返回了 result.toDataStreamResponse()
  3. 前端是否使用了 useCompletion 或 useChat
  4. 浏览器 Network 面板查看请求状态
```

## 数据库问题

### SQLite 文件权限

```
问题：SQLITE_CANTOPEN: unable to open database file

解决：
  1. 确保 data/ 目录存在：mkdir -p data
  2. 检查目录权限：ls -la data/
  3. 确保 .gitignore 没有阻止文件创建
```

### 表不存在

```
问题：SQLITE_ERROR: no such table

解决：
  执行数据库迁移：pnpm db:push
  检查 schema.ts 中的表定义是否正确
```

### Turso 连接失败

```
问题：连接 Turso 数据库超时

检查：
  1. TURSO_DATABASE_URL 格式是否正确（libsql://...）
  2. TURSO_AUTH_TOKEN 是否有效
  3. 网络是否能访问 Turso 服务
```

## 构建问题

### TypeScript 类型错误

```
问题：构建时报类型错误

解决：
  1. 本地运行 pnpm build 查看具体错误
  2. 检查是否有 any 类型未处理
  3. 确保所有 import 路径正确
```

### 内存不足

```
问题：JavaScript heap out of memory

解决：
  export NODE_OPTIONS="--max-old-space-size=4096"
  pnpm build
```

## 部署问题

### Vercel 构建失败

```
问题：Deployment failed

检查：
  1. 本地 pnpm build 是否成功
  2. 查看 Vercel 构建日志
  3. 环境变量是否配置
  4. Node.js 版本是否兼容
```

### 环境变量未生效

```
问题：本地正常，部署后 API 调用失败

解决：
  1. 在 Vercel 项目设置中添加环境变量
  2. 重新部署（环境变量变更需要重新部署）
  3. 检查变量名是否正确（区分大小写）
```

### 冷启动慢

```
问题：首次访问很慢

原因：Serverless 函数冷启动

优化：
  1. 使用 Edge Runtime（更快的启动）
  2. 减少依赖包大小
  3. 使用 Vercel 的预热功能
```

## 常见报错速查表

| 错误信息 | 原因 | 解决方案 |
|---------|------|---------|
| `401 Unauthorized` | API Key 无效 | 检查 Key 和环境变量 |
| `402 Payment Required` | 余额不足 | 充值 |
| `429 Too Many Requests` | 请求太频繁 | 等待或降低频率 |
| `SQLITE_CANTOPEN` | 数据库文件无法打开 | 检查目录和权限 |
| `Module not found` | 依赖未安装 | pnpm install |
| `Hydration failed` | 服务端/客户端渲染不一致 | 检查 "use client" 使用 |
