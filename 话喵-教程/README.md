# 话喵 — AI 智能创作平台开发教程

> 从前端开发者到 AI 应用开发者，一个项目搞定

## 这是什么？

这是一套完整的 AI 应用开发教程。你将从零开始，一步步构建一个名为「话喵」的 AI 写作平台，最终部署上线。

**话喵**的核心功能：
- **文章创作器**：输入标题，AI 生成格式化文章，支持选择字数、风格、详细程度
- **古诗词生成器**：输入一个名词，AI 创作古诗词，附带注释和赏析
- **风格文库**：导入你喜欢的文章，AI 学习其风格后进行仿写

## 适合谁？

- 有前端基础（React/Vue）的开发者
- 想转型 AI 应用开发但不知从何入手
- 面试被问"有没有 AI 项目经验"想有东西可讲

## 技术栈

| 层级 | 技术 | 用途 |
|------|------|------|
| 框架 | Next.js 15 + TypeScript | 全栈 Web 应用 |
| UI | Tailwind CSS + shadcn/ui | 界面设计 |
| AI | Vercel AI SDK | 流式输出、前端 Hooks |
| RAG | LangChain.js | 文档处理、Embedding、向量检索 |
| LLM | DeepSeek | 大语言模型（兼容 OpenAI SDK） |
| 数据库 | SQLite + Drizzle ORM | 数据持久化 |
| 部署 | Vercel | 一键上线 |

## 学习建议

```
1. 按章节顺序学习，每章都有前置依赖
2. 每章结束后动手验证，确认效果再继续
3. 不理解的概念先跳过，实践中会慢慢理解
4. 遇到问题先看附录的常见问题
5. 预计总学习时间：40-60 小时
```
