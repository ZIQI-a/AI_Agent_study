## 本章目标

**要做的事**：用 Vercel AI SDK 实现流式输出，让 AI 回复逐字显示

**学到的知识**：
- 为什么需要流式响应（用户体验差异）
- SSE（Server-Sent Events）原理
- Vercel AI SDK 的 `streamText` 和 `useCompletion`
- 流式协议的工作方式

## 5.1 为什么需要流式？

```
非流式（上一章的方式）：
  用户发送 → 等待 5-10 秒 → 一大段文字突然出现
  
  体验：用户以为卡了，可能关掉页面

流式（打字机效果）：
  用户发送 → 第 1 秒开始出字 → 逐字显示 → 完成
  
  体验：用户看到 AI 在"思考"和"打字"，有实时反馈
```

这就像前端的加载状态 —— 用户不怕等，怕的是不知道在等什么。

## 5.2 SSE 原理

SSE（Server-Sent Events）是一种服务器向浏览器推送数据的技术。

```
普通 HTTP 请求：
  浏览器 ──请求──→ 服务器
  浏览器 ←─完整响应─ 服务器
  （一次性返回所有数据）

SSE 流式：
  浏览器 ──请求──→ 服务器
  浏览器 ←─chunk1─ 服务器  （第 1 个字）
  浏览器 ←─chunk2─ 服务器  （第 2 个字）
  浏览器 ←─chunk3─ 服务器  （第 3 个字）
  ...（持续推送）
  浏览器 ←─done──  服务器  （结束信号）
```

前端类比：
```
普通请求 = fetch()，等全部完成
SSE      = EventSource，持续接收
WebSocket = 双向通信（SSE 是单向，服务器→浏览器）
```

## 5.4 服务端：streamText

创建 `src/app/api/generate/route.ts`：

```typescript
import { streamText } from "ai";
import { createOpenAI } from "@ai-sdk/openai";

// 创建 DeepSeek provider
const deepseek = createOpenAI({
  apiKey: process.env.DEEPSEEK_API_KEY,
  baseURL: "https://api.deepseek.com",
});

export async function POST(req: Request) {
  const { prompt, system } = await req.json();

  const result = streamText({
    model: deepseek("deepseek-chat"),
    system: system || "你是一个有帮助的AI助手，请用中文回答。",
    prompt,
    maxTokens: 2000,
    temperature: 0.7,
  });

  // toDataStreamResponse() 把流式结果转为标准响应
  return result.toDataStreamResponse();
}
```

**关键代码解释**：

```typescript
streamText({
  model: deepseek("deepseek-chat"),  // 使用哪个模型
  system: "...",                       // System Prompt
  prompt: "用户输入",                  // 用户消息
  maxTokens: 2000,                     // 最大输出 Token
  temperature: 0.7,                    // 温度
});

// streamText 返回一个 Stream 对象
// toDataStreamResponse() 把它转为浏览器可读的流式响应
```

> **知识点：streamText vs 之前的 chat.completions.create**
> ```
> chat.completions.create：
>   等待全部生成完 → 一次性返回完整结果
>   const response = await client.chat.completions.create(...)
>   return response.choices[0].message.content  // 完整文本
> 
> streamText：
>   生成一个字就返回一个字
>   const result = streamText(...)
>   return result.toDataStreamResponse()  // 流式响应
> ```

## 5.5 前端：useCompletion Hook

Vercel AI SDK 提供了 React Hook，让流式调用变得非常简单。

创建 `src/app/test-ai/stream/page.tsx`：

```typescript
"use client";

import { useCompletion } from "@ai-sdk/react";
import { Button } from "@/components/ui/button";
import { Textarea } from "@/components/ui/textarea";
import { Card, CardContent, CardHeader, CardTitle } from "@/components/ui/card";
import { PageContainer } from "@/components/layout/page-container";

export default function StreamTest() {
  const { completion, input, handleInputChange, handleSubmit, isLoading, error } =
    useCompletion({
      api: "/api/generate",
    });

  return (
    <PageContainer title="流式测试" description="体验打字机效果">
      <div className="space-y-6">
        {/* 输入区 */}
        <form onSubmit={handleSubmit} className="space-y-4">
          <Textarea
            value={input}
            onChange={handleInputChange}
            placeholder="输入你想让 AI 写的内容..."
            rows={3}
          />
          <Button type="submit" disabled={isLoading}>
            {isLoading ? "生成中..." : "开始生成"}
          </Button>
        </form>

        {/* 输出区 */}
        {completion && (
          <Card>
            <CardHeader>
              <CardTitle className="text-lg">AI 生成结果</CardTitle>
            </CardHeader>
            <CardContent>
              <div className="whitespace-pre-wrap leading-relaxed">
                {completion}
                {/* 光标闪烁效果 */}
                {isLoading && (
                  <span className="inline-block w-0.5 h-5 bg-primary animate-pulse ml-0.5" />
                )}
              </div>
            </CardContent>
          </Card>
        )}

        {/* 错误提示 */}
        {error && (
          <div className="text-red-500 text-sm">错误：{error.message}</div>
        )}
      </div>
    </PageContainer>
  );
}
```

访问 `http://localhost:3000/test-ai/stream`，输入内容点击生成，你会看到文字逐字出现。

## 5.6 useCompletion 的工作原理

```typescript
const { completion, input, handleInputChange, handleSubmit, isLoading } =
  useCompletion({ api: "/api/generate" });

// 当用户提交表单时：
// 1. handleSubmit 发送 POST 请求到 /api/generate
// 2. 请求体自动包含 { prompt: input }
// 3. 服务端 streamText 开始生成
// 4. 前端通过 SSE 接收每个 chunk
// 5. completion 自动更新，React 重新渲染
// 6. 用户看到文字逐字出现
```

内部流程：

```
用户输入 → handleSubmit → POST /api/generate
                              ↓
                        streamText() 开始生成
                              ↓
                        chunk1 → completion = "你"
                        chunk2 → completion = "你好"
                        chunk3 → completion = "你好，"
                        chunk4 → completion = "你好，我是"
                        ...
                        done → isLoading = false
```

## 5.7 传递 System Prompt

我们可以让前端指定 System Prompt，实现不同的生成风格。

修改 `src/app/api/generate/route.ts`：

```typescript
import { streamText } from "ai";
import { createOpenAI } from "@ai-sdk/openai";

const deepseek = createOpenAI({
  apiKey: process.env.DEEPSEEK_API_KEY,
  baseURL: "https://api.deepseek.com",
});

export async function POST(req: Request) {
  const { prompt, system, maxTokens, temperature } = await req.json();

  const result = streamText({
    model: deepseek("deepseek-chat"),
    system: system || "你是一个有帮助的AI助手，请用中文回答。",
    prompt,
    maxTokens: maxTokens || 2000,
    temperature: temperature ?? 0.7,
  });

  return result.toDataStreamResponse();
}
```

前端可以传更多参数：

```typescript
const { completion, input, handleInputChange, handleSubmit, isLoading } =
  useCompletion({
    api: "/api/generate",
    body: {
      system: "你是一个专业的技术博客作者，文章风格简洁明了。",
      maxTokens: 3000,
      temperature: 0.8,
    },
  });
```

`body` 中的额外参数会自动合并到请求体中。

## 5.8 使用 useChat（对话式流）

`useCompletion` 是单次补全，`useChat` 是多轮对话。

创建 `src/app/test-ai/chat-stream/page.tsx`：

```typescript
"use client";

import { useChat } from "ai/react";
import { Button } from "@/components/ui/button";
import { Input } from "@/components/ui/input";
import { Card, CardContent } from "@/components/ui/card";
import { PageContainer } from "@/components/layout/page-container";

export default function ChatStream() {
  const { messages, input, handleInputChange, handleSubmit, isLoading } =
    useChat({
      api: "/api/chat-stream",
    });

  return (
    <PageContainer title="流式对话" description="多轮对话 + 流式输出">
      <div className="space-y-4">
        {/* 消息列表 */}
        <div className="space-y-3 max-h-[500px] overflow-y-auto">
          {messages.map((msg) => (
            <div
              key={msg.id}
              className={`flex ${msg.role === "user" ? "justify-end" : "justify-start"}`}
            >
              <Card
                className={`max-w-[80%] ${
                  msg.role === "user" ? "bg-primary text-primary-foreground" : ""
                }`}
              >
                <CardContent className="py-2 px-4">
                  <p className="text-sm whitespace-pre-wrap">
                    {msg.content}
                    {isLoading && msg.id === messages[messages.length - 1]?.id && (
                      <span className="inline-block w-0.5 h-4 bg-current animate-pulse ml-0.5" />
                    )}
                  </p>
                </CardContent>
              </Card>
            </div>
          ))}
        </div>

        {/* 输入框 */}
        <form onSubmit={handleSubmit} className="flex gap-2">
          <Input
            value={input}
            onChange={handleInputChange}
            placeholder="输入消息..."
            disabled={isLoading}
          />
          <Button type="submit" disabled={isLoading}>
            发送
          </Button>
        </form>
      </div>
    </PageContainer>
  );
}
```

创建对应的 API Route `src/app/api/chat-stream/route.ts`：

```typescript
import { streamText } from "ai";
import { createOpenAI } from "@ai-sdk/openai";

const deepseek = createOpenAI({
  apiKey: process.env.DEEPSEEK_API_KEY,
  baseURL: "https://api.deepseek.com",
});

export async function POST(req: Request) {
  const { messages } = await req.json();

  const result = streamText({
    model: deepseek("deepseek-chat"),
    system: "你是一个有帮助的AI助手，请用简洁的中文回答。",
    messages,
  });

  return result.toDataStreamResponse();
}
```

## 5.9 流式响应的数据格式

了解底层数据格式有助于调试：

```
// SSE 数据格式（每行是一个事件）
data: {"type":"text-delta","textDelta":"你"}

data: {"type":"text-delta","textDelta":"好"}

data: {"type":"text-delta","textDelta":"，"}

data: {"type":"text-delta","textDelta":"我"}

data: {"type":"text-delta","textDelta":"是"}

data: {"type":"finish","finishReason":"stop"}

data: [DONE]
```

Vercel AI SDK 自动处理这些格式，你不需要手动解析。但如果遇到问题，可以在浏览器的 Network 面板中查看原始数据。

## 本章小结

| 概念 | 说明 |
|------|------|
| 流式响应 | 数据分块传输，逐字显示，用户体验好 |
| SSE | Server-Sent Events，服务器向浏览器推送数据 |
| streamText | Vercel AI SDK 的服务端流式生成函数 |
| useCompletion | 前端 Hook，单次补全，自动处理流式 |
| useChat | 前端 Hook，多轮对话，自动处理流式和历史 |
