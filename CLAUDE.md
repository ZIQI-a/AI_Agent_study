## Repository Purpose

This is a learning repository for a frontend developer studying AI Agent technology. It contains documentation, learning notes, and example code for transitioning from traditional frontend development to AI application development.

## Structure

- Documentation files are in Chinese (zh-CN), numbered for reading order
- Example code will be added in `examples/` directory
- Each example is self-contained with its own README

## When Working Here

- Documentation is the primary content — maintain accuracy of technical concepts
- Code examples should use TypeScript/JavaScript to leverage the user's frontend background
- Prefer practical, runnable examples over theoretical explanations
- When adding code examples, include package.json and clear setup instructions
